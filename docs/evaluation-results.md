## Answer / abstain threshold

The minimum retrieval score below which the tutor says "not in the course material" was selected on a **dev split** (25 items) by best F1 (most conservative value among ties) and then measured on a **held-out split** (24 items):

| Split | Threshold | Precision | Recall | F1 |
|---|---|---|---|---|
| Dev | 0.06 | 0.95 | 1.0 | 0.974 |
| Held-out | 0.06 | 1.0 | 1.0 | 1.0 |
| All items at the configured default (0.12) | 0.12 | 1.0 | 0.973 | 0.986 |

**Score overlap.** The lowest-scoring in-scope question scores 0.068 and the highest-scoring out-of-scope question scores 0.087. These ranges overlap, so no single threshold separates the classes perfectly (lexical retrieval cannot tell "control" in networking from "control" in concurrency control). The shipped default (0.12) is deliberately set above the highest out-of-scope score: it prefers declining a borderline question (the tutor still lists the closest lessons) over giving a wrong answer. The small held-out split is fragile; do not read its 1.0 as a guarantee.

## How to read these numbers

- The question set is small and written by the project author against the same notes the index is built from, so treat the figures as a **regression baseline and sanity check**, not as a benchmark of real-world performance. Real student questions are noisier.
- Faithfulness is high by construction in offline mode (answers are extracted sentences). With a hosted LLM, the output guard removes sentences that are not lexically supported by the retrieved passages, but fluent paraphrase can still be wrong; keep human review on AI-generated quizzes (they are saved as drafts).
- Offline quiz questions are cloze-style (one key term blanked). They are valid and traceable but pedagogically simple; a hosted model produces richer questions.
